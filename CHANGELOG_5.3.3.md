# DrawWise 5.3.3

## Personal history import and sidebar fix

- Adds **Import history file** directly to the normal Smart Pick sidebar.
- Accepts CSV/delimited result files and Excel `.xlsx` / `.xlsm` workbooks.
- Imports only for the game currently selected in DrawWise.
- Shows a preview with accepted rows, new records, corrections and final history size before writing anything.
- Creates an automatic backup before a manual import is applied.
- Renames **Refresh results** to **Update online results** for clarity.
- Fixes the Advanced button by opening the Advanced workspace in the current application process instead of relaunching the frozen EXE.
- Replaces the clipped bottom version text with a visible version label beside the DrawWise brand.
- Makes **Advanced Tools** a full-width visible button.
- Smart Ensemble number-selection logic is unchanged.

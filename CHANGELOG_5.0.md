# DrawWise 5.0 — Smart Pick

- Replaced the data-heavy default workspace with a personal Smart Pick screen.
- Normal workflow is now Game → Lines → Generate My Numbers.
- Added a new Smart Pick selection strategy that combines historical ranking, broad candidate generation, pair-history tie-breaking, balance and low-overlap portfolio optimisation.
- First generated line is clearly marked Recommended; remaining lines are alternatives.
- Added local Saved Picks history.
- Added a compact Refresh Results workflow for the currently selected game.
- Moved Number Analysis, Data Manager, Results Updater, Backtest, Strategy Lab and Methodology behind Advanced Tools.
- Preserved all V4.1 online updater safeguards and analytical functionality.
- Updated desktop packaging to launch the simplified Smart Pick UI by default.

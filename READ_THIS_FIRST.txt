DrawWise 5.4.0 — Maximum Intelligence
=====================================

The normal workflow remains simple:
1. Select the lottery game.
2. Select the number of lines.
3. Select the optimisation objective.
4. Click GENERATE MY NUMBERS.

The V5.4 engine now performs whole-portfolio optimisation, overlap control,
Randomness Gate historical shrinkage, local/evolutionary refinement and a
Monte Carlo challenge against random portfolios.

Result-history maintenance remains available from the left sidebar:
- Update online results
- Import history file

Advanced Tools remains available from the always-visible navigation button.

Run RUN_TESTS.bat to execute the 59-test regression suite.
